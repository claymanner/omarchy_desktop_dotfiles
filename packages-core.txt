# Core "work anywhere" package set — for the laptops (Legion, yoga).
#
# Additive only: shell/dev/remote-access/comms userspace. Deliberately EXCLUDES
# anything the machine's own Omarchy install owns (kernel, bootloader, sddm,
# pipewire, mesa/vulkan, microcode) and anything desktop-specific (NVIDIA stack,
# 32-bit gaming libs, Steam/Proton, controller DKMS, OpenRGB/ddcutil, 3D-printing
# slicers, media production). Install with:
#
#   grep -vE '^[[:space:]]*(#|$)' packages-core.txt | yay -S --needed --noconfirm -
#
# NOTE the grep: `yay -S - < packages-core.txt` feeds the comment lines in as
# package names and dies with `database not found: # ...`. packages.txt has no
# comments so it can be piped raw; this file cannot.
#
# See packages.txt for the older full-desktop snapshot.
